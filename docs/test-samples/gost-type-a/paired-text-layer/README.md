# Одна страница с текстовым слоем и без него

Папки `specification` и `drawing` содержат векторный `scan-vector.pdf`, соответствующий PDF только с изображением `scan-raster.pdf`, отдельный `template.pdf` и сохранённые области `template.pdf.template.json`. Оба входных документа созданы из одних заранее заданных полей; растр получен отрисовкой вектора, без повторного набора текста. Физические размеры страницы и координаты полей совпадают. Шрифт — закреплённый ГОСТ типа А, полностью встроенный в вектор.

Это синтетические макеты двух основных надписей. Общая таблица в верхней части даёт признаки для совмещения страницы; варианты различаются высотой основной надписи и наличием поля вида документа. В сохранённом прогоне обе проверки прошли, а средняя разница пикселей векторной и растровой версии при 250 DPI равна нулю.

`verification.json` относится только к целостности образцов и извлечению текстового слоя. Он записывается после проверки точных строк внутри выбранных областей, отсутствия текстового слоя у растровой версии и близости изображений. Этот отчёт **не утверждает успешное OCR или переименование**: для них нужна отдельная проверка настоящими движками. Векторный текст также требует независимой проверки по видимым символам.

Регенерация только этих двух пар на поддерживаемом окружении с нативными библиотеками PDFium/OpenCV/Skia:

```bash
DTR_GOST_PAIR_OUTPUT="$PWD/docs/test-samples/gost-type-a/paired-text-layer" \
  dotnet test tests/Core.Tests -c Release \
  --filter FullyQualifiedName~GostTypeAPairedPdfTests
```

Без `DTR_GOST_PAIR_OUTPUT` тесты используют временную папку. Исходные пять демонстрационных PDF и предыдущие результаты ГОСТ не затрагиваются. Поля совпадают с ранее исследованными регрессионными примерами, поэтому эти пары не являются независимой итоговой выборкой для обучения модели.
