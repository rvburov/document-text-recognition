# ГОСТ, тип А: отдельный диагностический набор

**Обновление V3:** выбранная до итоговой оценки специализированная модель дала
4 точных результата из 6 прежних PDF, включая исходный пример без поворота.
В окончательной регрессионной проверке 8 новых пар получены 5/8 точных векторных
и 2/8 точных растровых документов;
ошибочных принятий нет, остальные случаи получили отказ. Реальные PDF, вырезки,
ответы движков и ограничения сохранены в [selected-v3](selected-v3/README.md).
Ниже оставлена история исходной проблемы; её старые файлы и результаты не заменены.

Образцы используют неизмененный **GOST 2.304-81 Type A Slanted** из
[релиза Metrolog v0.7.6](https://github.com/Metrolog/Font.GOST2.304-81/releases/tag/v0.7.6).
Точный файл шрифта, источник, SHA256 и встроенная лицензия SIL OFL 1.1 находятся в
[`tests/Core.Tests/Fonts`](../../../tests/Core.Tests/Fonts/GOST-Type-A-SOURCE.md).
Генератор открывает этот файл напрямую и проверяет хеш. Подмена на DejaVu или другой
установленный шрифт запрещена. Эта реализация типографики не подтверждает, что
шрифт и экспорт PDF пользователя идентичны. Исходный проблемный PDF пока не получен.

Эталонные строки заданы в тесте до распознавания:

- Обозначение: `УИЕС.468732.271`.
- Наименование в две строки: `Плата УПЧ` / `1489 МГц`.
- Проверки смешанных алфавитов: `Плата Epcos USB` и `Плата Epcos` / `USB 1489 МГц`.

OCR получает только пиксели и назначение поля. Файлы имеют нейтральные имена,
а отдельный шаблон содержит другие примерные значения. Ожидаемый текст нельзя
получить из имени файла или шаблона. Отсутствие типа документа явно сохранено
в настройке шаблона.

В `crops/` находятся первые вырезки без рамки, полученные Pillow/FreeType:
высота прописной буквы 3,5 мм, 300 DPI. Параметры и хеши записаны в
`crop-fixtures.json`. Каталог `direct-fields/` сохраняет **исторический неудачный
baseline**, полученный Skia с тем же шрифтом: обозначение 5 мм, наименования 3,5 мм,
300 DPI. В JSON записаны исходные ответы обоих настоящих движков, уверенность
и результаты разбора. Разные растеризаторы дают разные пиксели, поэтому их
оценки уверенности нельзя сравнивать как результаты на одном изображении.

В исходной проверке Tesseract прочитал обозначение как `9/ЕС468732271` с
уверенностью 0,182, а Paddle как `YIEC.468732.271` с уверенностью 0,914.
Paddle прочитал наименование верно, Tesseract вернул `Гиата УПЧ 1489 My`.
Таким образом, ошибка воспроизводится и без цветной рамки. Высокая уверенность
сама по себе не доказывает правильность текста.

Исторические тесты профилей записали результаты в `current-profile-verification/`.
Они используют реальные профили полей, штатные пороги уверенности и обычную
сверку двух движков. Разрешен точный результат либо явный отказ с причиной;
принятие неверного значения проваливает тест. Смешанное наименование с латиницей
обязательно должно быть подтверждено правильно.

Сквозная проверка использует PDF только с растровой страницей и сохраненными
нормализованными прямоугольниками. Проверяются координаты диагностических
вырезок, исходная страница, поворот на 90 градусов и перекос на 1,2 градуса.
Каждый вариант читается с включенным и выключенным быстрым чтением строк.
Экспортируется один исходный образец с отдельным шаблоном и разметкой; остальные
варианты временные. Хеши PDF после OCR должны остаться прежними. Числа точных
результатов, отказов и неверных принятий учитываются отдельно. Успешное выполнение
этого теста безопасности **не означает, что все документы ГОСТ распознаны**.

Исторический прогон до подключения модели ГОСТ завершился `2/2 PASS` в Linux, без пропусков тестов.
При этом фактические результаты распознавания таковы:

| Проверка | Точно | Отказ | Неверно принято |
| --- | ---: | ---: | ---: |
| Отдельные поля, оба режима | 2 | 6 | 0 |
| Сочетания обозначения и наименования | 0 | 6 | 0 |
| PDF: исходный, 90 градусов, перекос 1,2 градуса, оба режима | 0 | 6 | 0 |

Два положительных результата относятся к `Плата Epcos USB`. Все шесть PDF
совместились с шаблоном, а обе сохраненные области были вырезаны по правильным
координатам. Документы отказались принимать из-за низкой уверенности Tesseract
в обозначении. На этом этапе проблема начертания оставалась нерешённой;
результаты последующей модели V3 приведены отдельно выше.

Исходный образец: [`scan.pdf`](current-profile-verification/fixture/scan.pdf),
отдельный [`template.pdf`](current-profile-verification/fixture/template.pdf) и
[разметка](current-profile-verification/fixture/template.pdf.template.json).
Подробные результаты:
[поля](current-profile-verification/direct-fields/verification.json) и
[PDF](current-profile-verification/end-to-end/verification.json).

Дополнительные изолированные эксперименты, не являющиеся поведением приложения:

- 72 сравнения через Tesseract CLI использовали одинаковые пиксели с текущими
  данными fast и официальными `tesseract-ocr/tessdata_best`, коммит
  `e12c65a915945e4c28e237a9b52bc4a8f39a0cec`; языки `rus+eng` или `rus`, PSM 6/7
  и ограничение алфавита обозначения кириллицей. Данные best улучшили некоторые
  наименования, но не прочитали обозначение правильно ни при одном размере.
  Загруженные модели, лицензия и хеши источника остаются только в
  `artifacts/tessdata-best/`; эти модели **не входят в поставку**.
- Фиксированная сетка из 36 вызовов на обозначении Skia высотой 5 мм использовала
  PSM 8/13, коэффициент обратного аффинного сдвига 0, -0,20 или -0,268,
  горизонтальное растяжение 1, 1,3 или 1,6 и общий либо кириллический профиль.
  Ни один вариант не вернул точное обозначение. Пропавшие точки и сомнительные
  буквы не восстанавливались из эталонного текста.
- Исходные TSV, хеши изображений и JSON этих экспериментов находятся в
  `artifacts/gost-probe/tessdata-comparison/` и `artifacts/gost-probe/rawline-grid/`.
  Уверенность слова в TSV отличается от уверенности строки, возвращаемой
  оберткой; в отчетах эти показатели обозначены отдельно.

Компактные результаты всех 72 + 36 сравнений с источниками моделей и SHA256
сохранены в [`investigation-summary.json`](investigation-summary.json).

В рамках этого набора не добавлялись новые модели OCR, угадывание символов,
снижение порогов или восстановление текста по имени файла. Пять исходных
демонстрационных PDF являются отдельным набором и здесь не пересоздаются.

Запуск в среде с поддерживаемыми нативными зависимостями:

```sh
DTR_GOST_OUTPUT="$PWD/docs/test-samples/gost-type-a" \
dotnet test tests/Core.Tests -c Release --filter FullyQualifiedName~GostTypeATests
```

Без `DTR_GOST_OUTPUT` новые отчеты сохраняются в выходном каталоге тестов.
