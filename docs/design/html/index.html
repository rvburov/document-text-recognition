Макет интерфейса «Переименование PDF» v0.1. Все экраны программы и дизайн-система. Открывается в любом браузере двойным щелчком по этому файлу, без интернета. Каждая доска интерактивна: кнопки, вкладки, диалоги и запуск работают как в программе (данные выдуманные). Оформление — строгий стиль Windows 11. Желтая метка «предложение» — возможность, которой нет в нынешней версии: ее можно принять или убрать.
