Главный экран. Две папки, «Искать в подпапках», ход работы и результат на одном экране. Нажмите «Запустить»: подтверждение, затем идет распознавание (счетчики, полоса, строки появляются по мере готовности), «Стоп» доступен. Вместо текстового журнала таблица «Было → Стало» с фильтром по итогу; «Сохранить журнал» сохраняет в Excel, CSV или текст. Желтые метки «предложение» отмечают то, чего нет в нынешней версии.

Запуск
Файлы в папке с PDF и ее подпапках будут переименованы на месте по распознанным обозначению и наименованию.

Содержимое файлов не меняется, ничего не удаляется; файлы, которые не удалось распознать однозначно, остаются с прежними именами.
Остановить
Остановить переименование? Файлы, которые уже в работе, дочитаются и не будут переименованы. Уже переименованные файлы останутся с новыми именами.
