Установка и обновление: тот же порядок, что в программах организации, один файл «Распознавание текста документов-Setup.exe». Двойной щелчок: установка для одного пользователя без прав администратора, ярлыки, запись в «Установленные приложения». Обновление берется из папки обновлений на сетевом диске (экран 6), удаление делается из «Установленных приложений», с выбором, удалять ли настройки.
