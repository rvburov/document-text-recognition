# Макет интерфейса «Распознавание текста документов»

**Актуальная версия v0.1 (HTML и CSS), 13.11.2026: [`html/index.html`](html/index.html).** Все экраны программы и
дизайн-система, интерактивно. Открывается в любом браузере двойным щелчком, без интернета. Данные в макете выдуманные.

Окно Windows (программа делается для Windows; Linux нужен только для проверок на GitHub). Оформление такое же, как у
программы резервного копирования организации ([backup-desktop-app](https://github.com/rvburov/backup-desktop-app),
`docs/UI_DESIGN.md`; решение владельца 13.11.2026): серо-голубой фон рабочей области `#F5F7FA`, панель разделов
`#ECEFF4`, белые карточки с рамкой `#DDE2E9`, синий акцент `#1F5FD1`, шрифты Golos Text и JetBrains Mono (`html/assets/fonts`,
SIL OFL 1.1), кнопки и поля высотой 32. Значения: `html/assets/tokens.css`, значки: `html/assets/icons.js`; те же
значения переносятся в стили программы.

Желтой меткой **«предложение»** отмечено то, чего нет в нынешней версии. Это можно принять или убрать; метки
скрываются флажком вверху страницы.

## Что где лежит

```
docs/design/
├── README.md          этот файл: экраны, решения, открытые вопросы
└── html/
    ├── index.html         все доски живыми миниатюрами
    ├── boards/NN-*.html   доска на экран
    └── assets/
        ├── tokens.css         токены оформления (цвет только через var(--pr-…))
        ├── icons.js           контуры значков, сетка 24 × 24
        ├── app.css            библиотека блоков (как стили программы)
        └── app.js             рамка окна, панель разделов, интерактивность
```

## Как устроено

- Программа «Распознавание текста документов»: одно окно с панелью разделов слева («Обработка», «Шаблоны»,
  «Настройки», внизу «О программе»); название программы только в заголовке окна. Окно 1180 × 760, наименьшее 760 × 560; диалоги 400 (вопрос) и 520 (форма).
- Режим один: переименование по содержимому скана (шаблоны и распознавание). Режима «По имени» и раздела «История»
  нет (решение владельца 13.11.2026).
- Распознавание и правила имени как в нынешней версии: папка шаблонов с цветными рамками, сверка Tesseract и PaddleOCR,
  имя «Обозначение Наименование.pdf», файлы только переименовываются.
- Вместо текстового журнала таблица «Было → Стало» с итогом по каждому файлу; журнал сохраняется в Excel, CSV или текст.
- Настройки хранятся в самой программе, в профиле пользователя Windows.
- Рамки шаблона: синяя (обозначение), зеленая (наименование), красная (оба поля вместе).
- Значки одного размера 16 с линией 1,9; кнопки внизу окна одной ширины.
- Установка: один файл «Распознавание текста документов-Setup.exe», для одного пользователя, без прав администратора.
  Обновление из папки обновлений на сетевом диске при запуске программы; интернет не нужен.

## Предложения (решает владелец)

1. Подробности файла справа от таблицы, «Ввести имя вручную» для пропущенных.
2. Вкладки-фильтры по итогу и поиск в результате.
3. Перетаскивание папки из Проводника.
4. «Проверить на скане» в разделе «Шаблоны».
5. Настройки: число одновременных файлов, что делать, если имя занято.

## Открытые вопросы

1. Установка одним файлом или папкой: компоненты распознавания занимают 400-500 МБ.
2. Компонент Microsoft Visual C++ 2015-2022 нужен распознаванию: класть его рядом с программой или проверять при запуске.

## Правила

- Цвет: только `var(--pr-…)` из `tokens.css`; размеры: из токенов.
- Тексты: как пишет сотрудник: без длинного тире в сообщениях программы, без буквы «е с точками», без эмодзи.
- Новый экран: новая доска `boards/NN-имя.html` и строка в списке `BOARDS` в `assets/app.js` и в таблице выше.
