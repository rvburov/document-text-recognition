# Макет интерфейса «Переименование PDF»

**Актуальный — v0.1 (HTML и CSS), 13.11.2026: [`html/index.html`](html/index.html).** Все экраны программы и
дизайн-система, интерактивно. Открывается в любом браузере двойным щелчком, без интернета. Данные в макете выдуманные.

Окно — Windows (программа делается для Windows; Linux — только для проверок на GitHub). Цвета, шрифт, размеры и значки —
те же, что в стилях программы: `html/assets/tokens.css` (цвета, шрифт, размеры) и `html/assets/icons.js` (значки).

Желтая метка **«предложение»** — возможность, которой нет в нынешней версии. Ее можно принять или убрать; метки
скрываются флажком вверху страницы.

## Что где лежит

```
docs/design/
├── README.md            — этот файл: экраны, решения, открытые вопросы
└── html/
    ├── index.html       — все доски живыми миниатюрами
    ├── boards/NN-*.html — доска на экран
    └── assets/
        ├── tokens.css   — токены оформления (цвет только через var(--pr-…))
        ├── icons.js     — контуры значков, сетка 24 × 24
        ├── app.css      — библиотека блоков (как стили программы)
        └── app.js       — рамка окна, панель разделов, интерактивность
```

## Как устроено

- Программа — одно окно с панелью разделов слева: «Переименование», «Шаблоны», «История», «Настройки», внизу
  «О программе». Окно 1100 × 720, наименьшее 900 × 600; диалоги — 420 (вопрос), 520 (форма), 800 (таблица).
- Распознавание и правила имени — как в нынешней версии: два режима, папка шаблонов с цветными рамками, сверка Tesseract
  и PaddleOCR, имя «Обозначение Наименование.pdf», файлы только переименовываются.
- Вместо текстового журнала — таблица «Было → Стало» с итогом по каждому файлу; журнал сохраняется в Excel, CSV или текст.
- Настройки и история хранятся в самой программе, в профиле пользователя Windows.
- Установка — один файл «Переименование PDF-Setup.exe»: для одного пользователя, без прав администратора. Обновление —
  из папки обновлений на сетевом диске, при запуске программы; интернет не нужен.

## Предложения (решает владелец)

1. Раздел «История» и возврат прежних имен (отмена прогона).
2. Подробности файла справа от таблицы, «Ввести имя вручную» для пропущенных.
3. Вкладки-фильтры по итогу и поиск в результате.
4. Перетаскивание папки из Проводника.
5. «Проверить на скане» в разделе «Шаблоны».
6. Настройки: число одновременных файлов, что делать, если имя занято, срок хранения истории.

## Открытые вопросы

1. Установка одним файлом или папкой: компоненты распознавания занимают 400–500 МБ.
2. Компонент Microsoft Visual C++ 2015–2022 нужен распознаванию: класть его рядом с программой или проверять при запуске.
3. Имя программы и папки данных выбрать до первого выпуска: потом его не меняют.

## Правила

- Цвет — только `var(--pr-…)` из `tokens.css`; размеры — из токенов.
- Тексты — как пишет сотрудник: без длинного тире в сообщениях программы, без буквы «е с точками», без эмодзи.
- Новый экран — новая доска `boards/NN-имя.html` и строка в списке `BOARDS` в `assets/app.js` и в таблице выше.
