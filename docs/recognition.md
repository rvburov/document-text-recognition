# Правила распознавания

## Шаблон

Шаблон: PDF в папке шаблонов, имя файла любое (например, «Спецификация.pdf»). На одной странице
поля штампа обведены цветными рамками:

| Рамка | Поле |
|---|---|
| синяя | обозначение |
| зеленая | наименование |
| желтая | тип документа |
| красная | все три поля в одной области |

Нужны либо синяя, зеленая и желтая рамки, либо одна красная. Рамка: контур без заливки, все
четыре стороны, не по тексту. Цвет определяется по тону, поэтому подходят оттенки из любого
редактора и после печати и сканирования. Оранжевый и салатовый не принимаются: непонятно, красный
это или желтый, желтый или зеленый. Шаблон без желтой рамки (старая разметка) не используется:
«нет желтой рамки (тип документа)».

## Скан

1. Страницы просматриваются по порядку (не больше 10). Страница, не похожая ни на один шаблон,
   пропускается (листы продолжения). Все подошедшие страницы должны дать одинаковые данные.
2. Скан совмещается с шаблоном (поворот, масштаб, сдвиг), из областей рамок вырезаются поля.
3. Каждое поле читают Tesseract и PaddleOCR. Поле принято, только если оба прочитали его
   одинаково после нормализации (пробелы, тире, «е с точками», буквы-двойники по правилу).
4. Обозначение проверяется по формату (ЕСКД с кодом документа, ЕСПД, технологические,
   отраслевые). Наименование: буквы есть, не больше 5 строк, внутри нет обозначения.
5. Тип документа: из желтой области как прочитан; если совпадает с типом из справочника
   (ГОСТ 2.102 и 2.701, например «Сборочный чертеж», «Схема электрическая принципиальная»),
   пишется как в справочнике. В красной области тип отделяется от наименования по справочнику
   (последняя строка, начинающаяся словом типа, или известный тип в конце строки).
6. **Тип на скане не написан** (поле пустое у обоих способов): ставится «Спецификация».

## Имя файла

«Обозначение Наименование Тип документа.pdf». Прямые кавычки заменяются одинарными; символы
`< > : / \ | ? *` в полях: файл пропускается (заменять их значило бы менять наименование).
Имя не длиннее 255 символов, полный путь не длиннее 259.

Имя занято другим файлом: по настройке файл пропускается или получает номер «(2)», «(3)» … до 99.
При повторном запуске файл с таким именем (и с номером, если включен номер) получает статус
«Имя уже верное».

## Статусы

| Статус | Когда |
|---|---|
| Переименован | все проверки прошли, файл переименован |
| Имя уже верное | у файла уже такое имя |
| Пропущен | данных для надежного имени не хватило или файл нельзя переименовать; причина в столбце «Стало» |
| Ошибка | непредвиденный сбой программы при обработке файла; подробности в журнале работы |

Пропущенному файлу и файлу с ошибкой можно ввести имя вручную (карточка файла): те же проверки.

## Работа в несколько потоков

Файлы распознаются параллельно (по умолчанию половина ядер, от 1 до 4; настройка «Одновременно
файлов»), у каждого потока свои Tesseract и PaddleOCR. Переименование идет по одному: занятость
имени проверяется прямо перед переименованием. «Стоп»: новые файлы не берутся, файлы в работе
дочитываются и не переименовываются.

## Пути с русскими буквами

Tesseract и PaddleOCR на Windows не открывают пути к своим данным с русскими буквами (например,
профиль «Иванов»). Программа передает им короткий путь Windows, а если его нет, копирует данные
в `%ProgramData%\DocumentTextRecognition`.
