# Сборка на ПК, установка и обновление

## 1. Что нужно один раз

1. **.NET SDK 10** для Windows x64: https://dotnet.microsoft.com/download/dotnet/10.0, раздел
   «SDK», файл «x64». Установить и проверить в PowerShell:
   ```
   dotnet --list-sdks
   ```
   В списке должна быть строка, начинающаяся с `10.`.
2. **Microsoft Visual C++ 2015-2022 Redistributable x64** на ПК, где идет сборка (обычно уже
   есть). Сборка кладет эти библиотеки рядом с программой, поэтому у пользователей устанавливать
   их не нужно.
3. Доступ к **nuget.org**: при первой сборке оттуда скачиваются библиотеки (около 1 ГБ).

## 2. Сборка

В папке репозитория (например, `E:\document-text-recognition`):

```
git pull
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

Сборка с тестами (дольше): добавить `-Test` в конец второй команды.

Результат: `dist\Распознавание текста документов-Setup.exe` (около 230 МБ; установленная программа занимает около 350 МБ). Сборка сама
проверяет, что оба способа распознавания запускаются; если нет, остановится с причиной.

Если nuget.org с ПК не открывается: на GitHub во вкладке **Actions** откройте последний запуск
**checks** для master, внизу в **Artifacts** скачайте `setup` (архив с тем же файлом). Файл
хранится 14 дней.

## 3. Установка

1. Положите `Распознавание текста документов-Setup.exe` в папку обновлений на сетевом диске,
   например `\\fileserver\Программы\document-text-recognition`.
2. Пользователь запускает файл двойным щелчком прямо из этой папки. Права администратора не
   нужны: программа ставится в `%LOCALAPPDATA%\Распознавание текста документов`, ярлыки в меню
   «Пуск» и на рабочем столе, запись в «Установленные приложения».
3. Папка, откуда запущен установщик, запоминается как папка обновлений (ее видно и можно
   изменить в окне установки и в «О программе»).

Windows может предупредить «Неизвестный издатель» (файл не подписан): «Подробнее», затем
«Выполнить в любом случае».

## 4. Обновление

1. Соберите новую версию (номер версии в `Directory.Build.props`, строка `<Version>`).
2. Замените файл в папке обновлений новым.
3. При запуске программа сравнивает свою версию с файлом в папке и предлагает установить.
   «Установить»: файл копируется, программа закрывается, ставит новую версию и открывается
   снова. Настройки сохраняются. Если замена не удалась (программа открыта еще раз), работает
   прежняя версия и говорит почему.

## 5. Удаление

«Параметры → Приложения → Установленные приложения → Распознавание текста документов →
Удалить». Можно удалить и настройки. Переименованные файлы не затрагиваются.

## 6. Где что лежит у пользователя

| Что | Где |
|---|---|
| Программа | `%LOCALAPPDATA%\Распознавание текста документов` |
| Настройки (`settings.json`) | `%APPDATA%\Распознавание текста документов` |
| Журнал работы (файл на день, 30 дней) | `%APPDATA%\Распознавание текста документов\Журнал` |

Проверка компонентов распознавания без окна:
```
"%LOCALAPPDATA%\Распознавание текста документов\DocumentTextRecognition.exe" --check
```
