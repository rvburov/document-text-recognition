# Распознавание текста документов

Программа для Windows: читает в штампе скана конструкторского документа обозначение, наименование
и тип документа и переименовывает PDF-файл в «Обозначение Наименование Тип документа.pdf»,
например «АБВГ.466229.001 Плата Спецификация.pdf». Файлы только переименовываются на месте,
содержимое не меняется, ничего не удаляется.

## Как работает

- **Шаблоны.** Выберите PDF-образец в разделе «Шаблоны» и откройте редактор. Выделите мышью
  обозначение синим, наименование зеленым, тип документа желтым или все поля вместе красным.
  Координаты сохраняются рядом с PDF в файле `.pdf.template.json`, оттенки исходного документа
  на эту разметку не влияют. Поддерживаются и старые PDF с уже нарисованными цветными рамками.
  Программа подбирает шаблон к каждому скану и совмещает их.
- **Два способа распознавания со сверкой.** Каждое поле читают Tesseract и PaddleOCR; имя
  ставится, только если оба прочитали одинаково. Иначе файл пропускается с причиной: лучше
  оставить старое имя, чем дать неверное.
- **Ускоренное чтение.** Модели PaddleOCR работают через ONNX Runtime; обозначение,
  наименование и тип читаются отдельно. Явно однострочные поля читаются без нейросетевого
  поиска строк; неподтвержденный ответ запускает полный поиск. Подбор шаблона автоматически
  использует возможности процессора с сохранением точности сравнения. Документы обрабатываются
  постоянными рабочими потоками; подтвержденные файлы переименовываются по очереди.
  Сверка с Tesseract остается обязательной.
- **Тип документа не написан на скане:** если оба движка видят пустое поле, в имя ставится
  «Спецификация». В редакторе можно явно указать отсутствие поля и сохранить только две области.
- **Статусы файлов:** «Переименован», «Имя уже верное», «Пропущен» (с причиной), «Ошибка»
  (сбой программы). Результат можно скачать в Excel, CSV или текст.
- **Большие списки.** Таблица проверена на 20 000 результатов: в контрольном окне создавались
  только 13 визуальных строк. Проверены прокрутка, поиск, фильтры и выбор последнего файла;
  [результаты теста](docs/performance/README.md#таблица-на-20-000-результатов).
- Все работает на этом компьютере, интернет не нужен; сканы никуда не отправляются.

В полном Windows-тесте выбранного режима 1.3.1 **8000 PDF обработаны за 20 минут 38,74 секунды**.
Все имена и SHA-256 совпали, ошибок и пропусков нет. Это копии четырех тестовых документов
на стенде с 4 vCPU; цель 15–20 минут не достигнута.
[Замеры и ограничения](docs/performance/README.md).

## Устройство репозитория

```
src/Core      распознавание: рамки шаблона, совмещение, Tesseract и PaddleOCR, имя файла, прогон
src/App       окно программы (Avalonia), выгрузка, обновление из папки обновлений, удаление
src/Setup     установщик «Распознавание текста документов-Setup.exe»
src/Common    общее для программы и установщика: пути, настройки, журнал, ярлыки
src/Ui        оформление по макету: цвета, шрифты, кнопки, поля, полоса прокрутки, значки
ocr/tessdata  языковые данные Tesseract (rus, eng)
tests         тесты ядра и окна (настоящее распознавание на синтетических сканах)
scripts       build.ps1: сборка на ПК; ci-ocr-deps.sh: компоненты для проверок на GitHub
docs          документация и макет
```

Проверки на GitHub (`.github/workflows/checks.yml`): тесты на Linux и сборка установщика на Windows.
