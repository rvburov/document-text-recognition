# Распознавание текста документов

Программа для Windows: распознает обозначение и наименование в штампе скана чертежа (шаблоны с цветными рамками,
Tesseract и PaddleOCR со сверкой) и переименовывает PDF-файл в «Обозначение Наименование.pdf». Файлы только
переименовываются, содержимое не меняется.

Сейчас в репозитории макет интерфейса: [docs/design](docs/design/README.md). Открывается двойным щелчком по
`docs/design/html/index.html`, без интернета.
