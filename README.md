# Распознавание текста документов

Программа для Windows: распознает обозначение, наименование и тип документа в штампе скана чертежа (шаблоны с цветными
рамками, Tesseract и PaddleOCR со сверкой) и переименовывает PDF-файл в «Обозначение Наименование Тип документа.pdf»,
например «АБВГ.466229.001 Плата Спецификация.pdf». Файлы только переименовываются, содержимое не меняется.

Сейчас в репозитории макет интерфейса: [docs/design](docs/design/README.md). Открывается двойным щелчком по
`docs/design/html/index.html`, без интернета.
